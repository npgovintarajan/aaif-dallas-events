Section 1

Event Architecture & Objectives

Engineered for systems architects, staff engineers, AI researchers, and technical leaders bridging the gap between toy prompts and production agent clusters.

TRACK A • MAIN AUDITORIUM 1:15 PM – 4:30 PM

Deep-Dive Systems Engineering

Focused on the hardest infrastructure challenges when scaling agentic workloads into enterprise production environments:

  • MicroVM & Wasm Sandboxes: AI-DLC runtime isolation, AWS Firecracker execution, memory safety, and sub-millisecond cold starts.
  • Gateways & Vulnerability Defense: Indirect prompt injection guards, confused deputy mitigation, egress filtering, and token firewalls.
  • OpenTelemetry Tracing & Audit Trees: Non-deterministic span propagation and cryptographically signed Evidence Artifacts.
  • Trajectory & Causality Metrics: Decision-tree efficiency, cyclic loop detection, and drift analysis vs. model hallucination.
TRACK B • HANDS-ON LAB 1:15 PM – 4:30 PM

Practical Implementation & Protocols

Facilitated, code-first workshops where engineers build, harden, and inter-operate production-grade agents in real-time:

  • Production MCP Server Construction: Exposing databases & ticket systems, Server-Sent Events (SSE), and Streamable HTTP auth.
  • Hardening MCP against Tool Poisoning: Defending against rug-pull attacks, hijacked schemas, and enforced gateway policies.
  • Agent Cards & A2A Discovery: Publishing /.well-known/agent.json and orchestrating async state lifecycles.
  • End-to-End Orchestrator Pipeline: Wiring orchestrators to remote A2A peers backed by private MCP servers using unified trace IDs.

Section 3

Technical Session Scope & Speaker Guide

Speakers and session leads must align their content with rigorous production depth, actionable code, and concrete architectural trade-offs.

01

Architecture Patterns & Workflows

Scope: Deterministic state machines vs. dynamic loops. Handling retry storms, infinite loops, and persistence models for multi-day runs.

Speaker Directive: Avoid abstract conceptual diagrams. Demonstrate concrete state recovery and HITL pause/resume logic using durable execution engines.
02

Internet of Agents & Discovery

Scope: Cross-organizational agent-to-agent negotiation protocols, dynamic catalogs, zero-trust perimeters, and capability matching.

Speaker Directive: Address practical cross-domain boundaries, untrusted metadata payloads, and latency costs of remote agent discovery.
03

Identity & Trust (SPIFFE/SPIRE)

Scope: User-delegated OAuth vs. machine-to-machine identities, cryptographic attestation, SPIFFE/SPIRE, and ephemeral credentials.

Speaker Directive: Highlight failure modes where agents escalate privileges via shared or over-permissioned service account keys.
04

Sandboxing & AI-DLC Runtimes

Scope: Docker containers vs. MicroVMs (AWS Firecracker) vs. Wasm isolation for executing untrusted agent code safely.

Speaker Directive: Benchmark startup latency, memory overhead, and file system isolation during runtime tool generation.
05

Gateways & Semantic Guardrails

Scope: Centralized proxy layers, token budget management, dynamic PII masking, and semantic policy checks prior to outbound calls.

Speaker Directive: Focus on real-time latency overhead introduced by guardrail proxies and async policy evaluation patterns.
06

Agentic Vulnerability Analysis

Scope: Threat modeling indirect prompt injection in RAG, confused deputy exploits, tool-poisoning, and lateral movement.

Speaker Directive: Walk through real-world attack trees and demonstrate concrete mitigation at application and gateway layers.
07

Observability & Evidence Artifacts

Scope: Mapping OpenTelemetry (OTel) across async decision trees. Generating cryptographically signed Evidence Artifacts for compliance.

Speaker Directive: Provide concrete JSON schema structures for span context propagation across heterogeneous agent frameworks.
08

Trajectory & Causality Evaluation

Scope: Evaluating non-deterministic agent runs: path optimality, redundant tool calls, trajectory drift, and context causality checks.

Speaker Directive: Contrast classical offline evaluation pipelines with continuous production trajectory monitoring.

Production MCP Servers & Hardening

Constructing enterprise-ready MCP endpoints and defending against tool poisoning and rogue parameter injection.

Module 1: Structured Resources & Tools

Expose databases and internal ticketing endpoints via standardized MCP JSON-RPC tool declarations.

Module 2: Transport Security & OAuth

Secure transport via Server-Sent Events (SSE) and Streamable HTTP with scoped OAuth tokens.

Module 3: Defending Against Tool Poisoning

Implement defensive schema validation to guard against rug-pull attacks designed to hijack model tool selection logic.

Implementing cross-agent communication protocols, asynchronous task states, and federated peer delegation.

Module 1: Standard Agent Cards
