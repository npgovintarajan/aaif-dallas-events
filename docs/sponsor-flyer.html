Why Sponsor Agentic AI Summit?

Connect with technical buyers and principal architects actively deploying agent runtimes, LLM gateways, and production sandboxes.

Dual-Track Program Architecture

TRACK A • AUDITORIUM Systems & Security
  • • MicroVMs & Runtimes: AWS Firecracker, Wasm & memory isolation.
  • • Gateways & Vulnerabilities: Prompt injection & egress policies.
  • • Observability: OpenTelemetry span trees & signed audit evidence.
  • • Trajectory Evaluation: Path optimality & drift grading metrics.
TRACK B • HANDS-ON LABS Code-First Protocols
  • • Lab 1: Production MCP Servers: SSE transport & scoped OAuth.
  • • Hardening MCP: Defending against tool poisoning & rug pulls.
  • • Lab 2: Multi-Agent A2A: Agent cards (/.well-known/agent.json).
  • • End-to-End Orchestrator: Peer delegation with unified trace IDs.
